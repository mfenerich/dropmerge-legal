# dropmerge-legal

Public legal pages for the Android game **Drop & Merge 2048**
(`com.marcelfenerich.dropmerge2048`).

## Publish with GitHub Pages

1. Create a new **public** repo, e.g. `dropmerge-legal`.
2. Add `index.html` (and this README) to the default branch.
3. Repo **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   branch `main`, folder `/ (root)`.
4. After ~1 minute the policy is live at:
   `https://mfenerich.github.io/dropmerge-legal/`
5. Paste that URL into Play Console → **App content → Privacy policy**
   and into the **Store listing**.

## Maintenance

- Update the "Last updated" date in `index.html` whenever the policy changes.
- When you enable analytics/diagnostics or additional ad networks, revisit
  Sections 2.3 and 4, and update the Play Console Data safety form **before**
  that version goes live.
